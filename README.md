# Real Estate Chatbot Website

Static GitHub Pages website built with HTML, CSS and minimal JavaScript.

## Files
- index.html
- about.html
- sales.html
- demo.html
- contact.html
- privacy.html
- terms.html
- style.css

## Deploy
Upload all files to a GitHub repository and enable GitHub Pages from the repository's Pages settings. Keep all files in the same directory so the relative links work.

Before advertising, review the Privacy Policy and Terms & Conditions against the actual business and data practices.
